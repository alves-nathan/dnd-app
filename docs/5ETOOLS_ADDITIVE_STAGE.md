## Boundary
`src/compendium/importV3AdditiveStage.ts` adds a pure, single-pack local session API. It accepts exact canonical V3 JSON text and caller-supplied installed compendium snapshot, runtime snapshot ID and reserved historical/runtime IDs. Reuses stageImportV3, never returns its V2 projection, never invokes a repository write, importer, catalog activation or transaction. Existing V1/V2 and runtime remain unchanged. Validates snapshot identity/FKs/status and rejects collisions with storage IDs, canonical IDs, sources, packs and reserved inventories; missing references are not satisfied via external IDs. Warnings remain review-required. Main upstream only, one declared commit, sourceCode-qualified source, needsReview source status; rejects Homebrew/manual/legacy origins at this boundary. Empty, invalid and oversized (>10 million JS code units) inputs fail closed. Exact raw text and SHA-256 bindings stay local, not published. checkAdditiveV3Stage recomputes the session from current context and raw text; never executable. No authenticity, rights, complete inventory, semantic parity, dependency closure, or approval inferred. Only physical ID collisions are checked, not equivalence or aliases. Single pack/session, no persistent queue/UI, no automatic pack merge or cross-pack grants. Caller-supplied inventories are observations and may be incomplete; no authorization depends on them. Serialized JSON ordering changes conservatively invalidate binding. No execution or redistribution is permitted.
