## Model and scope
One immutable collection, structural audit and converter run set; optional shared context in tag/semantic/resource/effect/variant reports, preserving standalone APIs. Main only; homebrew remains structural and namespace-isolated. No changes to conversion eligibility, V3 contract, owner validation, physical IDs, payloads or runtime. Ledger keeps independent denominators: raw coordinates, physical emitted IDs, evidence occurrences. Coverage states emitted, outsidePilot, gapWithStructuralCandidate, gapWithoutCandidate, templateNoOutput; candidate is not emission. Existing baseline remains authority for staging validity; integrated ledger checks identity/coordinates/source/commit/blob/stage scope/activation, not a substitute for stageImportV3. Source/kind local coverage and bootstrap aggregate; no names or raw upstream text in CI output.
- Attach evidence from references, precedence/reprint, external templates, version specs, owner aliases and grants, magic candidates/verification, inline/UID/spell structures, semantic requirements/choices/grants, resources/profiles/costs, damage/scaling/conditions/defenses/durations/saves. Each evidence occurrence has a canonical SHA256 fingerprint of snapshot pair, source coordinate, payload, domain, ordinal and endpoints. Raw data not copied into ledger, but hash derived from full evidence. Optional local JSON may include upstream-derived provenance/identifiers; do not publish.
- Cross-owner complete aliases remain structural candidates; check raw target coordinate, no owner rewrites, no new subclass or feature emitted. Versions belong to parent coordinate, not standalone emitted identities. Magic pair candidate linked to template and checks base. Compatibility is recalculated from exact emitted endpoint metadata, never from consumer edition alone; missing endpoints remain pending. Different domains may represent the same reference; occurrence counts not unique entities or coverage gain.
- Review decisions acceptEvidence/rejectEvidence/defer require exact evidenceId/fingerprint, both commits, explicit approval, reviewer and reason. Conflicting duplicates rejected. Acceptance changes only review field, not activation/coverage. No approvals supplied. No schema extension until global graph/runtime decisions.
