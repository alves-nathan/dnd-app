# a8.10.2 — Creature combat projection

Binds the remaining-family evidence and re-derives creature payloads using the retained resolved record and existing converter. Classifies literal size, type, AC, HP, walking/movement, ability scores, CR/PB, saves and skills. Attributed or alternative AC, dynamic HP, hover/conditional movement and multiple sizes stay pending. HP average must match the floored explicit dice expectation. No tactical-reader default or first-option selection is treated as mechanical evidence.

Actions remain bound to their source section, index and fingerprint. Only converter-qualified single-hit, single-type attacks with explicit range/reach and bounded dice qualify, and only with caller-confirmed targeting and excluded dependencies. Reactions, multiattack, recharge, spellcasting, legendary/lair/mythic actions and traits remain pending. Preview returns range band and damage bounds, not a hit, advantage, damage roll or action expenditure. Literal damage/condition defenses are separately inventoried; conditional and combined defenses are not flattened. A defense membership preview requires confirmed inventory and excluded other defenses; absence is not proof of no mechanic.

The static chassis preview returns disposable values with explicit HP and position, no tactical target insertion, encounter mutation, initiative, resource or effect changes. The legacy tactical reader, converter and runtime are unchanged. Only aggregate counts and report fingerprint logged; no new workflow, clones or dependencies.
