# a8.13.3 — Auxiliary inventory and local coherence

Adds explicit hydrated projections of distribution, publication, transparency, rollout health/aggregation and operational audit/authorization/federation stores, with reference guards and active download/operational-session blocking. Aggregation records include only contributor-secret presence, not secret bytes. No new hydration or mutation. Store projections are observations, not independently verified persisted data.

Strict bounded package index/chunk reads reuse repository key/byte-length helpers. Checks descriptor identities, active/previous references, chunk shape/count/byte length, SHA-256 of raw text and declared bundle version. Limits: 64 packages, 512 chunks, 32 MB aggregate declared bytes. Reads twice and rechecks the index after chunks. Missing, corrupt, over-budget and changed packages are not successful observations. Only hashes/counts/status leave the capture. Loaded stored package reference/version/snapshot/checksum comparison is separate from trust/rights. Bundled ref only is not byte evidence. Legacy backend raw envelope compared to observed compendium using same inventory digest; SQLite and IndexedDB not independently read because their existing opens may initialize storage. No claim of atomic capture, unindexed chunks, download cache contents, durable backup, full completeness or cutover.

Four additional synthetic regression tests use actual memory repository package staging (fixture only), corruption, mismatch and concurrent mutation. Next a8.13.4: read-only inventory panel, clear coherence/status indicators and explicit revalidation/expiry. Remaining backend and external inventory obligations stay open.
