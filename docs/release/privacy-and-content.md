# Privacidade e conteúdo importado

Este app é offline-first e foi estruturado para não embutir regras oficiais protegidas de D&D no binário.

## Conteúdo de regras

- O app inclui apenas fixtures autorais/mecânicas genéricas para testes.
- Conteúdo de livros deve ser importado pelo usuário a partir de material obtido legalmente.
- O compêndio salvo localmente pode conter trechos ou dados derivados da sua biblioteca privada; não distribua backups/exports com conteúdo que você não tem direito de compartilhar.

## Dados locais

Persistências locais usadas pelo app:

- Zustand/AsyncStorage para personagens, cenários, presets e histórico.
- SQLite local para o compêndio.
- Backups/exportações JSON gerados pelo próprio usuário.

## Antes de compartilhar builds

- Compartilhar o binário do app não deve incluir seu compêndio local, mas sempre revise fixtures e assets.
- Compartilhar arquivos JSON de compêndio ou backup pode compartilhar conteúdo privado/importado.
- Para testes com terceiros, prefira usar a biblioteca de exemplos autorais.
