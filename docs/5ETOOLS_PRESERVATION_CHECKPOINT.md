## Boundary
`src/compendium/importV3Preservation.ts` binds the current V3 stage, exact repository export (persistence v3), current character backup v3 with portable catalog audit, complete supplied PortableRestoreDataCheckpoint, current catalog snapshot graph and active package ref into a SHA-256 local evidence manifest. Reuses existing stage, backup parser and portable audit APIs. Rejects stale stage, registry inventory mismatch, invalid export, partial/corrupt backup, invalid/duplicate entity IDs, normalized content differences and catalog audit mismatches. Requires equality of all four portable backup entity collections, filters, history, revision and remediation plans; exact full checkpoint hash additionally covers drafts, recovery, quarantine. Revalidation recomputes evidence. Manifest contains hashes/counts only, no payload, never executable. Older backups still supported by the existing reader, not accepted as complete current preservation evidence. Does not prove that supplied state is genuine, complete, durable or jointly captured; does not capture runtime package bytes, cryptographic trust, transparency or external history/user installations. No executor, UI, migration, activation or persistence change. SHA-256 is a binding, not an authorization.
