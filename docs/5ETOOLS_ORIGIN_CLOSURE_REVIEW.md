## Implementation
- origin-closure-review.js binds three reports by canonical digests, common commits, exact unique origin identity and source fingerprint, edition/kind, variant/feat evidence, parent endpoint and historical occurrence coverage. Aggregates only. Does not independently authenticate the source or approve semantic equivalence.
- originPreservationPreview.ts isolated review of one pre-existing size choice on disposable legacy creation draft and character. Requires validated stored item, declared same source version, explicit selection policy and exclusion of other origin dependencies, exact allowed size options and previous choice. Creation draft checks canonical choice references; character checks exact active stored link, source, previous size and full snapshot. Only selected size and choice may change (creation draft only choice); all other fields, including attributes, proficiencies, grants, spells, resources, effects, equipment, links and transaction history, are preserved. No general respec, new creation, migration, choice entitlement, size-dependent rules, or actual persistence. Strict JSON comparison may reject harmless representation/order differences; no timestamp changes allowed in this isolated draft preview.
- Four added tests in origin grant suite: exact closure, disposable actual mapper/size choice helper, tampered state/stale binding/duplicates, canonical creation draft. Real aggregate structural assertion. No new dependency, workflow, clone, runtime call site or character mutation. CI pending; no full local suite.
